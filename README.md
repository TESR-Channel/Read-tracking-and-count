# TESR Track Count — อ่านเลขพัสดุ & นับจำนวนจาก PDF

เว็บแอปภายในของ TESR Logistics · อัปโหลด (หรือลากวาง) ใบปะหน้าพัสดุแบบ PDF แล้วระบบจะ

- ดึงเลข Tracking ทุกกล่อง (ไปรษณีย์ไทย / EMS `AB123456789TH`, Flash, SPX, Kerry, Lazada, Ninja)
- อ่านจำนวนสินค้าจากบรรทัด “รายการสินค้า” เช่น `(2ตัว)(1)` = 2 ตัว, `x3`, `3 ชิ้น`
- จัดกลุ่ม **สินค้า → จำนวนต่อกล่อง** เช่น 1 ตัว 8 ออเดอร์ / 2 ตัว 2 ออเดอร์ / 3 ตัว 1 ออเดอร์
- คัดลอกสรุปไปวางใน LINE, คัดลอกเลขรายกลุ่ม, ดาวน์โหลด CSV (เปิดใน Excel ได้), พิมพ์ใบแพ็ค
- ติ๊ก “แพ็คแล้ว” ทีละกล่อง และแก้จำนวนเองได้ถ้า PDF อ่านไม่ออก (แสดงสีส้ม)

ไฟล์ PDF ถูกอ่านในเบราว์เซอร์ด้วย [pdf.js](https://mozilla.github.io/pdf.js/) — **ไม่มีการอัปโหลดข้อมูลลูกค้าขึ้นเซิร์ฟเวอร์**
ใช้ได้บนคอม, iPad และมือถือ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ + สไตล์ (TESR CI โทนสว่าง) |
| `app.js` | UI: อัปโหลด, render กลุ่ม, คัดลอก, CSV, พิมพ์ |
| `parser.js` | ตัวอ่านใบปะหน้า (ไม่มี dependency, ทดสอบด้วย Node ได้) |

## เพิ่มรูปแบบเลขพัสดุ / หน่วยนับ
- รูปแบบเลขพัสดุ: `TRACKING_PATTERNS` ใน `parser.js` (หรือใส่ Regex ในหน้าเว็บ › ตั้งค่าขั้นสูง)
- หน่วยนับ: `UNIT_WORDS` ใน `parser.js`

## รูปแบบใบปะหน้าที่อ่านได้ (v1.3)
- รายการในบรรทัดเดียว: `ชื่อสินค้า(1 ตัว)(2)`, `x2`, `×2`, `*2`, `(x2)`, `Qty: 2`, `จำนวน 2 ชิ้น`, `2 ตัว`
- หลายสินค้า: คั่นด้วย `,` `;` หรือขึ้นบรรทัดใหม่, ลิสต์เลขลำดับ `1.` `2)` และ bullet `-` `•`
- ชื่อสินค้ายาวที่ถูกตัดขึ้นบรรทัดใหม่, บรรทัด `Qty:` / `จำนวน:` แยกบรรทัด
- ตาราง `ชื่อสินค้า … SKU … จำนวน` (TikTok / Shopee / Lazada)
- ยอดรวมบนใบปะหน้า (`จำนวนรวม`, `Qty Total`) ใช้ตรวจทาน — ถ้าไม่ตรงจะขึ้น "?" ให้คนตรวจ
- หยุดอ่านเมื่อเจอฟิลด์ถัดไป (วันที่สั่งซื้อ, หมายเหตุ, ผู้รับ, COD, เบอร์โทร, ที่อยู่ ฯลฯ)

ทดสอบตัวอ่าน: `node test-parser.mjs`
